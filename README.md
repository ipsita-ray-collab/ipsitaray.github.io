# Ipsita Ray — Academic Website

This is a static GitHub Pages website designed for an academic/research profile.

## Structure

- `index.html` — homepage
- `research.html` — past/current research
- `teaching.html` — teaching philosophy, experience and mentoring
- `cv.html` — CV overview + downloadable PDF
- `personal.html` — personal photographs and informal content
- `style.css` — shared styling
- `documents/` — CV, research statement and teaching statement PDFs
- `assets/` — images

## Add your images

Place these files in `assets/`:

- `headshot.jpg`
- `personal1.jpg`
- `personal2.jpg`
- `personal3.jpg`

The current `personal.html` uses placeholders until those three photographs are added.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `ipsitaray.github.io`.
2. Upload all files and folders from this project to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save. GitHub will publish the site at `https://ipsitaray.github.io/` if the repository is named `ipsitaray.github.io`.

## Updating the site

The content is deliberately kept in ordinary HTML/CSS so it can be edited directly on GitHub without a build system. Update the research cards as projects evolve, and replace the PDFs in `documents/` when you have new versions.
